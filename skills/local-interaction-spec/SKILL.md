# 本地交互式产品说明书

## 启用范围与界面风格

仅在用户明确选择、点名或要求使用此 Skill 时执行本流程。普通 Demo 请求按正常方式制作，不自动附加左右联动说明、本地说明编辑与查看版导出功能。

启用时沿用已确认的清爽界面：保留 Demo、说明目录、详细设计与业务正文、编辑／保存／导出按钮、版本号和更新时间。去掉与主要功能无关的辅助小字、教学提示、示例标签、顶部说明条和底部重复介绍。保留必要的加载、错误、未保存和文件生成反馈；示例数据及待确认业务的性质在相关规格正文中说明，不用重复标签占据界面。

## 交付目标

把可操作原型和详细设计说明放在同一份本地交付物中。左侧体验页面、控件和状态；右侧展示对应业务场景及具体规格，服务后端与 UI/UX 设计师。概念词如“状态可见性”只作辅助标签，不替代详细说明。

默认流程：本地编辑 → 保存新版本 → 导出查看版 → 用户自行发送文件。无需托管、联网账号或在线发布。Skill 负责指导制作这些文件，本身不是已经实现的编辑器。

## 使用已有材料

先确认已有 Demo、PRD、设计截图及本次范围，复用当前会话已确认的方案。若只要概念图或讨论，交付到该阶段；若要求实施，继续完成文件及验证。具体产品和必要业务规则缺失时仅澄清影响正确性的部分。

保留用户提供的原稿与官方资产。识别确认事实、示例行为和待确认事项，不把示例接口、价格、权限、奖励或状态枚举变成正式规则。已有目标文件时就地做范围内修改并保留原版本，避免重建丢失原交互。

## 文件与联动约定

- 编辑版与查看版均优先交付可通过浏览器直接打开的独立 HTML；所需样式、脚本、图像和说明内嵌，避免 CDN、绝对本地路径和必须运行服务器的依赖。
- 给场景、交互和状态设置稳定 ID，建立元素到说明的映射。点击既执行原交互，也定位右侧说明；切换页面或弹窗后仍显示所属场景，避免说明脱离上下文。
- 右侧以完整设计说明为主，按场景、交互、状态组织。选择区域与实际操作冲突时提供明确的说明选择方式，不让查看说明改变业务流程。
- 编辑版允许修改说明正文与结构化字段；编辑中的点击、输入不会误触 Demo。保存最新修改，包括当前焦点中的输入。
- 查看版隐藏编辑、保存源文件等工具，保留 Demo 操作、说明导航、版本号与更新时间。隐藏编辑入口只是查看体验，不是保密或防篡改措施。

说明编写时读取 [references/spec-content.md](references/spec-content.md)；实现保存及导出时读取 [references/local-files.md](references/local-files.md)。

## 验证与交付

检查真实交互到说明的映射、返回及弹窗层级；验证修改 → 保存 → 关闭 → 重开后文字与版本仍在。将保存文件改名或移入其他目录，确认打开不受影响；检查查看版内容与当前保存版本一致、编辑工具已隐藏、无外部资源依赖。

用未登录、空数据、失败等真实存在的状态验证说明和界面对应。无后端时明确标注演示数据，不能宣称接口联调通过。能进行浏览器操作时检查桌面双栏与窄屏布局；若工具或权限阻塞，保留文件并说明未验证项，不把静态检查称为浏览器验收。

交付时提供编辑版与查看版的绝对路径链接，说明如何修改、保存和导出。只有新文件生成及必要检查完成才声明相应步骤完成；创建此 Skill 不等于已交付可用 Demo。
