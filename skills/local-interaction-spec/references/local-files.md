# 本地编辑、保存新版本、导出查看版

## 编辑文件是可靠源

编辑版 HTML 内含可恢复的说明数据、映射和版本信息。浏览器 localStorage 可以用于草稿恢复，但不能作为“已保存到本地文件”的证据；用户改名、换目录、换浏览器或发送文件后，数据仍需存在于文件本身。

浏览器不能默认静默覆盖任意源文件。默认“保存新版本”生成新的编辑版 HTML 并由浏览器下载；明确告诉用户是生成新文件。若使用文件选择器或 File System Access API，先做能力检测，只有用户授予该文件写入权限后才执行写入，并提供下载回退。文件名只是下载建议，允许用户随意重命名，不将路径或名称作为数据 ID。

## 保存的内容

保存时将最新编辑数据完整序列化，记录 documentId、schemaVersion、revision、updatedAt、mode，以及稳定的场景／元素／状态映射。revision 首次保存为 1，之后成功保存新版本加 1；每次版本递增和时间更新绑定一次文件生成或写入，纯打开或浏览不改变元信息。

时间用 ISO 8601 保存并标注显示时区，默认尊重当前用户时区，显示时明确标注时区。旧版本文件各自保留原来的 revision 和 updatedAt，文件重命名不改变它们。

下载文件生成后可提示“已生成新版本，请在浏览器下载记录中确认”，不能声称已验证用户磁盘落盘。实际写文件时根据成功结果更新保存状态；取消选择或写入失败保持未保存提示，不留下假的成功提示。

## 查看版导出

导出查看版使用已保存快照，保留相同 revision 和 updatedAt；导出行为本身不增加修订号。存在未保存修改时明确提示先保存新版本，再导出相应查看版，避免界面内容、源文件与分享版本不一致。导出失败可重试，不覆盖编辑源文件。

查看版内嵌该版本 Demo、说明和资源，去掉编辑工具，保留所有用于演示和阅读的必要交互。若未确认实际后端，仅使用明确标注的演示数据，不把凭证、密钥、个人数据或开发日志打包分享。

## 序列化与离线运行

使用安全的数据序列化方式。例如内嵌 JSON 时转义可能终止 script 元素的字符，展示普通文字用 textContent；富文本需要限定格式与安全处理。保存时不抓取瞬时弹窗、编辑选区或临时 DOM 作为唯一源，应从规范数据和模板生成文件，防止嵌套脚本、重复监听与运行状态污染。

离线文件不能依赖 fetch 本地 JSON、外部字体、CDN 脚本、远端图片或绝对路径。大量素材导致单文件过大时向用户说明实际影响并确认交付形式，不自行改成在线发布。

## 必要检查

- 编辑含中文、换行、引号及特殊字符的说明，保存并重开，内容一致。
- 连续保存两个版本，旧文件与旧元信息不变，新文件版本和时间正确。
- 导出的查看版与对应保存快照一致，仍可操作 Demo，不能显示编辑工具。
- 文件重命名、换目录后不丢失说明或资源；离线打开正常。
- 保存取消、失败和未保存导出有明确反馈，避免误认为内容已保存。

导出 HTML 是可编辑的文件格式；查看版隐藏入口不等于访问控制、保密或防篡改。
